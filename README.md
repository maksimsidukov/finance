# Обязательные платежи

PWA для учёта обязательных платежей: квартира, интернет, подписки, кредит.

## Возможности

- Список платежей: название, сумма, день месяца, комментарий
- Отметка «оплачено» одним нажатием, подсветка просроченных и ближайших платежей
- Сводка по периоду: оплачено / всего, прогресс-бар
- Кнопка «Новый период» — текущий период уходит в историю, отметки обнуляются
- Автоматический переход на новый период при смене месяца
- История всех закрытых периодов со статусами и суммами
- Работает офлайн (service worker), устанавливается на телефон как приложение

## Расчёт зарплаты (вкладка «Зарплата»)

- Оклад до НДФЛ, дни выплаты аванса и расчёта, расчёт в текущем или следующем месяце
- Аванс — пропорционально отработанным дням 1–15 (произв. календарь) или фикс. % от оклада
- НДФЛ по пятиступенчатой прогрессивной шкале 13–22% (ФЗ № 176-ФЗ), нарастающим итогом с января
- Производственный календарь РФ: праздники по ст. 112 ТК + переносы по постановлению
  Правительства № 1466 (2026); дни выплат на выходных сдвигаются на предыдущий рабочий день (ст. 136 ТК)
- График выплат на 12 месяцев вперёд. Годы без постановления о переносах (2027+)
  считаются по базовому правилу ТК и помечаются «календарь примерный» — после выхода
  постановления нужно дописать переносы в `src/lib/workCalendar.ts`

## Данные

Всё хранится локально в `localStorage` браузера — без сервера и аккаунтов.
Данные не синхронизируются между устройствами и пропадут при очистке данных браузера.

## Разработка

```bash
npm install
npm run dev      # дев-сервер
npm run build    # production-сборка в dist/
npm run preview  # локальный просмотр сборки
```

Стек: React 19 + TypeScript + Vite 7 + Tailwind CSS + shadcn/ui + vite-plugin-pwa.

## Деплой на GitHub Pages

1. Залейте содержимое этой папки в репозиторий (ветка `main`).
2. В репозитории: **Settings → Pages → Source → GitHub Actions**.
3. Push в `main` — workflow `.github/workflows/deploy.yml` сам соберёт и опубликует сайт.

`base: './'` в `vite.config.ts` делает пути относительными, поэтому приложение работает
для любого имени репозитория (`user.github.io/<repo>/`) без правок конфига.
